# 版本状态

## 当前阶段

Monica Steam 仍处于公开测试阶段，而不是稳定正式版。

测试版意味着：

- UI 和接口可能继续调整；
- Steam 上游变化可能导致功能临时失效；
- 数据结构可能继续迁移；
- 网络优化策略仍可能继续修正；
- 风控风险仍需要持续观察。

## 当前主要能力

现阶段项目已覆盖：

- Steam Guard 与账号管理；
- 游戏库和个人游戏内容；
- Steam 商店；
- 好友、聊天与通知；
- 备份和本地安全；
- 动态 DNS / DoH；
- 静态 Hosts 扫描；
- 自定义 UDP DNS / HTTPS DoH；
- 原生 Steam 页面与内置网页能力。

## 更新时

以项目 Releases、仓库 README 和 Release Notes 为准。升级前务必备份 Steam Guard / `maFile`。
