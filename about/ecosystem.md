# Monica 生态关系

## Monica Pass

Monica Pass 是 Monica 生态中的本地优先密码管理方向项目，具有自己的文档站与 Android 能力。

## Monica Steam

Monica Steam 从 Monica Android 的 Steam 模块独立出来，作为专注 Steam 的 Android 客户端维护。

两者在设计语言上可以共享：

- Material 3 / Expressive 风格；
- Monica 系列视觉元素；
- 本地优先与安全边界理念；
- 部分基础 Android 组件。

但产品定位和数据域不同。

## 数据不自动共享

Monica Steam 和 Monica Pass 可以并排安装，但 Android 应用沙箱相互独立，不会自动共享密码库、Steam 令牌或数据库。
